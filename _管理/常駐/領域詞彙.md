# 領域詞彙 — 本專案專屬語言

> **目的**：建立本專案的共同語彙，讓你和 AI 用同一組詞溝通。
> **效果**：一個詞取代一段解釋 → 溝通更精準、省 context、子 Agent 行為更一致。
> **維護時機**：開案時建立初始詞條；開發中每當出現「需要解釋兩次以上的概念」就補一條。

---

## 使用規則（給主 Agent）

1. **開案時**：腦力激盪過程中，把反覆出現的業務概念記成詞條（不需要一開始就完整）
2. **開發中**：發現自己或使用者用一長句描述某個概念、且**已經是第二次**了 → 立刻收斂成一個詞條
3. **委派時**：若本次任務涉及此處詞條，把相關詞條附在委派 prompt（或指明子 Agent 讀此檔）
4. **命名原則**：用**使用者說得出口的詞**，不要用實作術語（例：用「訂單」不用 `OrderEntity`）
5. **有實作對應時標註**：讓子 Agent 知道這個業務詞對應程式碼裡的什麼

> ⚠️ **這裡放「業務/領域概念」，不放技術棧規則**。技術棧規則的單一來源是 `專案規格.md` 的 STACK_RULES。
