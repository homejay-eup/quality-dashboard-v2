## 產品概述

- 產品名稱：設備品質分析儀表板 v2
- 核心功能一句話描述：把設備的派工／維修／報廢／回廠資料彙整成品質指標，取代原本「手動用 Excel 彙整 → 上傳儀表板」的流程；純前端直接讀 Google Sheet，即時彙整、免上傳
- 目標使用者：內部品管／採購同事，透過瀏覽器開網址直接看
- 最在意的面向：彙整邏輯要跟「規則定義文件」一致（規則變了兩條產出路徑要同步），資料來源鮮度（即時讀取 vs 需要快照才能跨期比較）

---

## 技術架構

- 前端 Web：純前端（`index.html` / `css/` / `js/`），**無框架、無打包器**，瀏覽器直接 fetch Google Sheet 的 gviz CSV 端點即時彙整
- 資料來源：公開可檢視的 Google Sheet「設備品質分析來源」（分頁：SQL上線量／SQL派工／SQL維修／SQL_報廢／SQL回廠時間／類型清單／維修分類等），免登入即可讀取
- 雲端輔助服務：Google Apps Script（`apps-script/Code.gs`）——Drive 對 Drive 複製，供「匯出本期快照」「跨期比較」使用，部署方式見 `apps-script/README.md`
- 離線批次腳本：Python（`新版產出/build_分析總表.py`）——讀 Google Sheet 快照，依規則產出 Excel 分析總表；**2026-09-21 起降級為參考用**，網頁已完整取代「人工整理 Excel」的舊流程，不再需要產生 Excel 分析總表，改規則時也不再要求同步更新這支腳本（見 `方案紀錄.md` #7）。檔案保留，不刪除
- 部署平台：GitHub Pages，直接從 `master` 分支根目錄部署（無 build 步驟、無 GitHub Actions，push 到 master 即生效於 https://homejay-eup.github.io/quality-dashboard-v2/ ）
- 認證：Google 登入閘（限 `@eup.com.tw` 網域，`js/auth.js`）
- 選型原因摘要：純前端＋直讀 Sheet＝免上傳，是這個專案存在的核心目的；GitHub Pages 免另建伺服器
- 排除選項：正式後端服務（Node/Python server）——沒有寫入正式資料庫的需求，靜態頁面已足夠

## 專案結構

```
專案根目錄/
├── index.html / css/ / js/         ← 前端主體（無打包器，直接部署）
├── apps-script/                    ← 雲端快照備份用 Google Apps Script
├── scripts/                        ← 前端用的輔助建置腳本（build_purchase_dates.py，產出 js/data/purchase_dates.json）
├── 設備品質分析_分冊文件/            ← 彙整邏輯規則定義（唯一來源），目前 v9；原本只存在本機，本次搬家補進版控
│   ├── 00_規則定義.md               ← 規則 A–F，改規則前必讀
│   ├── 00_變更紀錄.md／00_共用設定.md／00_來源對照表.md／00_冊次索引.md／00_待整理清單.md
│   └── 01~07 分冊（資料庫彙整操作/問題排查、分析總表規格、多期合併、成本節省計算、整體架構）
├── 新版產出/                        ← Python 批次腳本產出路徑（Excel 分析總表），原本只存在本機，本次搬家補進版控
│   ├── build_分析總表.py            ← 主批次腳本，RULE_DOC_VERSION 需與 00_規則定義.md 同步
│   ├── build_summary_POC.py／verify_分冊文件_vs_xlsm.py
│   └── HANDOFF_交接文件.md
└── （其餘為範本既有結構：_管理/常駐、_管理/範本、_管理/SOP、.claude/）
```

> ⚠️ `新版產出/` 原本還有 3 個各 9–10MB 的 `.xlsx` 快照與 `__pycache__`，屬產出物/快取，搬家時**刻意不帶過來**（需要時重新產生即可，不要進版控）。
> 「目前進度／下一步」的單一來源是 `_管理/常駐/此次任務.md`，本檔不重複記錄。

## 規範與約定

- 命名規則：沿用範本既有規則（中文檔名、無底線前綴、無流水號）；`js/`、`css/`、`scripts/`、`apps-script/` 是既有 repo 慣例，維持英文小寫
- UI 語言：中文（繁體）
- 不要動的東西：改 `js/transform.js` 前，必須先確認 `設備品質分析_分冊文件/00_規則定義.md` 是否也要同步更新版本號。Python 批次腳本已降級為參考用（見上方技術架構），不再要求跟著同步
- 產出物迭代：`index.html`／`js`／`css` 就地覆蓋，版本歷史靠 git；`新版產出/` 的 Excel 分析總表屬一次性產出物，不進版控（已在 `.gitignore` 排除）
