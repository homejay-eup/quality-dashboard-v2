# 任務報告範本

> ⚠️ 空白格式範本。實際報告檔存 `_管理/任務報告/{編號}-{任務名}.md`。
> 大型任務分解情境下，每個子任務一個報告檔：`{編號}-{任務名}.md`
> 由執行該任務的子 Agent 邊做邊寫；中斷後可讀回自己的報告復原進度，不依賴主 Agent 記憶。
> reviewer 審查該任務時一併讀此檔。
>
> 日常單一任務不需要建報告檔（口頭回報 + commit 已足夠）。

## 報告檔格式

```markdown
# 任務 {編號}：{任務名}

- 狀態：進行中 / 完成 / 卡住
- 允許改動清單：（從任務分解.md 複製）

## 進度
- [x] 步驟 1：寫測試 → 確認紅燈（輸出：1 failed）
- [ ] 步驟 2：實作

## 遇到的問題
（卡住的地方、做過的嘗試、為什麼不通）

## 驗證證據
- 指令：`npx playwright test xxx`
- 輸出：3 passed, 0 failed
```

> 涉及畫面呈現時，視覺化驗證見 `CLAUDE.md`「🖼️ 視覺化優先」（此提示不需複製進實際報告檔）
