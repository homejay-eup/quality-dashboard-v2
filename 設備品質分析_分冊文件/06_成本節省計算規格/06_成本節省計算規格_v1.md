# 冊 06：成本節省計算規格

---

## 第一節：說明與目的

### 功能說明

本冊記錄「節省維運金額計算」模組的設計與規格，包含：

1. **成本參數設定.xlsx**：獨立存放的參數參考檔，記錄各廠牌型號整新單價與系統參數（時薪、運費、工時）。由人工維護，不隨季度改變，腳本每次執行時自動讀取。

2. **成本節省總覽工作表**：計算結果工作表，由冊 05 Step 5 Python 腳本自動產出，寫入多期合併版 `設備品質分析_分析總表.xlsx`。

3. **Dashboard 成本節省分頁**：quality-dashboard.html 讀取 `成本節省總覽` 工作表，顯示節省金額 KPI 卡、圖表與明細表（需另行更新 HTML，見第三節規格）。

### 計算範圍

- **設備類型**：車機、鏡頭、配件、耗材（全四類）
- **觸發條件**：`維修分類 = '不送修'`（設備回廠後 CRM 判斷無需送外修，內部整新）
- **節省邏輯**：每台不送修設備，省下送外修的整新費用 + 運費；另計算內部耗用工時

### 計算公式

```
整新單價合計（每廠牌型號）
  = 成本預估中同廠牌型號所有操作的整新單價加總（Option A）
  例：鏡頭 HS = 整新 1050 + 整線 500 = 1550 元

節省金額合計
  = (整新單價合計 + 每件運費) × 不送修數量
  例：HS 10 台 = (1550 + 130) × 10 = 16,800 元

耗費工時_分鐘
  = 每件工時(分鐘) × 不送修數量
  例：HS 10 台 = 3 × 10 = 30 分鐘

工時成本_元
  = 耗費工時_分鐘 × 時薪 ÷ 60，四捨五入至整數
  例：30 分鐘 × 196 ÷ 60 = 98 元
```

## 第二節：成本參數設定.xlsx — 建立與維護

### 檔案位置

放置於與 `設備品質分析_分析總表.xlsx` 相同的工作資料夾，**不放入任何子資料夾**。

```
工作資料夾/
├── 成本參數設定.xlsx          ← 本節建立的參數檔
├── 設備品質分析_分析總表.xlsx
├── 設備品質分析_分析總表_25_Q1.xlsx
└── 設備品質分析_分析總表_26_Q1.xlsx
```

### 工作表一：成本預估

**說明**：記錄各廠牌型號各操作類型的整新單價。同一廠牌型號可有多列（如整新、整線），腳本計算時自動加總（Option A）。

**欄位定義：**

| 欄位名稱 | 格式 | 必填 | 說明 |
|---------|------|------|------|
| 設備類型 | 文字 | 必填 | 車機 / 鏡頭 / 配件 / 耗材 |
| 廠牌型號 | 文字 | 必填 | **必須與彙整總表的廠牌型號欄位格式完全一致** |
| 操作類型 | 文字 | 選填 | 整新 / 整線 / 其他（供人工識別，不影響計算） |
| 整新單價 | 整數（元）| 必填 | 該操作項目的費用 |
| 來源 | 文字 | 選填 | 資料來源說明，如「整新品循環-CRM不送修」、「內部QC-人工紀錄」 |
| 備註 | 文字 | 選填 | 補充說明 |

**範例資料：**

| 設備類型 | 廠牌型號 | 操作類型 | 整新單價 | 來源 |
|---------|---------|---------|---------|------|
| 車機 | S168 | 整新 | 100 | 整新品循環-CRM不送修 |
| 車機 | GO-168 | 整新 | 650 | 整新品循環-CRM不送修 |
| 鏡頭 | HS | 整新 | 1050 | 整新品循環-CRM不送修 |
| 鏡頭 | HS | 整線 | 500 | 整新品循環-CRM不送修 |
| 車機 | HS | 整新 | 200 | 內部QC-人工紀錄 |

> **廠牌型號格式一致性**：成本預估中的廠牌型號必須與 `設備品質分析_彙整總表` 的「廠牌型號」欄位完全一致（包含空格、大小寫、括號）。如不一致，腳本 join 失敗時整新單價合計會為 0，並顯示警告。

### 工作表二：系統參數

**說明**：記錄全域計算參數，時薪或費用調整時只需修改此處，不需改動腳本。

**欄位定義：**

| 欄位名稱 | 格式 | 說明 |
|---------|------|------|
| 參數名稱 | 文字（作為 index） | 固定值，不可更改（腳本以此 key 讀取） |
| 值 | 數字 | 當前設定值 |
| 說明 | 文字 | 人工備注用 |

**固定內容（參數名稱不可更改）：**

| 參數名稱 | 值 | 說明 |
|---------|-----|------|
| 時薪 | 196 | 法定基本時薪（元/小時），依勞基法調整時更新 |
| 每件運費 | 130 | 平均每件設備運費（元），依實際運費調整 |
| 每件工時 | 3 | 平均每件設備整新作業工時（分鐘） |

> ⚠️ `參數名稱` 欄位的文字必須與上表完全一致，腳本以此作為讀取 key。若需新增參數，需同步修改 Step 5 腳本。

### 初次建立步驟

1. 在工作資料夾新建 Excel 檔，命名 `成本參數設定.xlsx`
2. 將工作表 1 命名為 `成本預估`
3. 依上方欄位定義填入標頭與資料（資料來自現有 `設備品質分析_資料庫_26_Q1_更新.xlsm` → `成本預估` 工作表）
   - **注意**：欄位名稱需按本冊規格調整（原始欄位「整新單價(維修費)」改為「整新單價」）
4. 新增工作表 2，命名為 `系統參數`
5. 依上方固定內容填入三列參數資料，確認 `參數名稱` 欄為 index 欄（A欄）
6. 儲存

### 維護時機

| 情況 | 更新工作表 | 說明 |
|------|-----------|------|
| 新增廠牌型號上線 | `成本預估` | 追加新型號的操作成本列 |
| 整新費用調整 | `成本預估` | 修改對應列的整新單價 |
| 法定時薪調整 | `系統參數` | 更新「時薪」欄的值 |
| 運費標準改變 | `系統參數` | 更新「每件運費」欄的值 |
| 整新作業流程改變 | `系統參數` | 更新「每件工時」欄的值 |

> 每次修改 `成本參數設定.xlsx` 後，需重新執行冊 05 Step 5 腳本，重建 `成本節省總覽` 工作表後再上傳。

## 第三節：Dashboard 成本節省分頁呈現規格

本節為 quality-dashboard.html 更新時的規格參考，說明成本節省分頁應讀取哪個工作表、顯示哪些資訊。

### 工作表讀取

| 工作表名稱 | 必填 | 行為 |
|-----------|------|------|
| `成本節省總覽` | 選填 | 存在時顯示成本節省分頁；不存在時隱藏該分頁，不影響其他分頁 |

### 欄位讀取對照

| 欄位名稱 | 資料型別 | 用途 |
|---------|---------|------|
| 期間 | 文字 | 期別篩選、YoY 比較；格式同彙整總覽（`2025-Q1`） |
| 設備類型 | 文字 | 分類篩選（車機 / 鏡頭 / 配件 / 耗材） |
| 廠牌型號 | 文字 | 型號篩選、排行圖 X 軸 |
| 廠商 | 文字 | 廠商篩選 |
| 不送修數量 | 整數 | KPI 計算 |
| 整新單價合計 | 整數 | 明細顯示 |
| 節省金額合計 | 整數 | KPI 計算、圖表 Y 軸 |
| 耗費工時_分鐘 | 整數 | KPI 計算 |
| 工時成本_元 | 整數 | KPI 計算 |

### KPI 卡規格（建議）

| KPI 名稱 | 計算方式 | 與現有 Dashboard 對應關係 |
|---------|---------|--------------------------|
| 當期節省金額（元） | `SUM(節省金額合計)`，依當期篩選 | 同 車機/鏡頭 各 KPI 卡的「當期」邏輯 |
| 節省金額 YoY | 當期 vs 前期 節省金額差值 | 同現有 YoY 比較 delta 顯示方式 |
| 不送修總件數 | `SUM(不送修數量)`，依當期篩選 | — |
| 總耗費工時（分鐘） | `SUM(耗費工時_分鐘)`，依當期篩選 | — |
| 工時成本合計（元） | `SUM(工時成本_元)`，依當期篩選 | — |

> **期別邏輯**：「當期」與「前期」的對應由使用者在 Dashboard 的期別選擇器中指定，與現有 `車機_彙整總覽` 的 current / comparison period 選擇器共用。

### 圖表規格（建議）

| 圖表名稱 | 類型 | X 軸 | Y 軸 | 分色依據 | 說明 |
|---------|------|------|------|---------|------|
| 節省金額排行 | 水平長條圖 | 節省金額合計 | 廠牌型號 | 設備類型 | 依節省金額降冪排序；同現有 Dashboard 長條圖風格 |
| 各類設備節省比較 | 堆疊長條圖 | 期間 | 節省金額合計 | 設備類型 | 呈現四類設備貢獻占比，含 YoY 對比 |
| 工時耗用排行 | 水平長條圖 | 耗費工時_分鐘 | 廠牌型號 | — | 了解整新作業人力負擔分布 |

### 篩選器規格（建議）

| 篩選器 | 型別 | 適用範圍 |
|--------|------|---------|
| 期間 | 多選下拉 | 全分頁 |
| 設備類型 | 多選下拉 | 全分頁（車機 / 鏡頭 / 配件 / 耗材） |
| 廠商 | 多選下拉 | 全分頁 |

### 明細表規格（建議）

顯示所有明細列，可依篩選器過濾：

| 欄位 | 顯示格式 | 備注 |
|------|---------|------|
| 期間 | 文字 | |
| 設備類型 | 文字 | |
| 廠牌型號 | 文字 | |
| 廠商 | 文字 | |
| 不送修數量 | 整數 | |
| 整新單價合計 | 金額（元）| 整新單價合計 = 0 的列建議以淡灰色樣式標示，提示使用者補充成本參數 |
| 節省金額合計 | 金額（元）| |
| 耗費工時_分鐘 | 整數 | |
| 工時成本_元 | 金額（元）| |

> ⚠️ `整新單價合計 = 0` 的列表示該廠牌型號尚未在 `成本參數設定.xlsx` 設定，節省金額僅計運費。此類列可以灰色或 `*` 標注，提醒維護人員補充後重跑腳本。

### 與現有工作表的讀取差異

| 比較項目 | 車機_彙整總覽（現有）| 成本節省總覽（新增）|
|---------|----------------|----------------|
| 設備類型涵蓋 | 僅車機 | 車機 + 鏡頭 + 配件 + 耗材 |
| 列的粒度 | 廠牌型號 × 期間 | 廠牌型號 × 期間 |
| 是否需要 | 必要 | 選填（不存在時分頁隱藏）|
| 主要用途 | 品質分析 | 成本效益呈現 |
