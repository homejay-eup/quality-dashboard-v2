## 一、已知問題記錄

### 問題 1：上線量欄位全為 0

**症狀：**
```
✓ 有上線量的品號: 0
✓ 平均上線量: 0.0
✓ 最高上線量: 0
```

**根本原因：**
- 上線量表的 `QP_Code` 和派工量表的 `ERP品號` 來自不同來源
- 派工量表本身無 `ERP品號` 欄位，需透過 VLOOKUP 類型清單表才能取得
- 直接 merge 導致無法正確對應

**排查過程：**

| 步驟 | 檢查項目 | 結果 |
|------|----------|------|
| 1 | 檢查派工量表欄位 | ❌ 無 ERP品號，僅有品項完工日期、替換前品項、替換前品項條碼等 |
| 2 | 檢查關聯表 | 類型清單表有 ERP品號，需透過「替換前品項」進行 merge |
| 3 | 驗證資料型別 | ERP品號：整數型；QP_Code：字串型（需轉換） |

**解決方案：**

```python
# 1. 先合併派工量與類型清單，取得 ERP品號
結果 = 派工量.merge(類型清單, on='替換前品項', how='left')

# 2. 統計上線量並確保資料型別一致
上線_統計 = 上線量.groupby('QP_Code').size()
結果['ERP品號_str'] = 結果['ERP品號'].astype(str).str.strip()

# 3. 使用轉換後的字串進行 merge
結果 = 結果.merge(上線_統計, left_on='ERP品號_str', right_on='QP_Code', how='left')
```

## 二、資料型別陷阱與預防策略

### 常見陷阱

| 陷阱 | 檢查方式 | 預防措施 |
|------|----------|----------|
| 數字 vs 字串 | `df['col'].dtype` | 統一轉換 + `.astype(str).str.strip()` |
| 空白字符 | `df['col'].str.len()` | `.str.strip()` |
| 日期格式 | `pd.to_datetime()` | 指定 `format` 參數 |
| NULL/NaN | `df['col'].isnull().sum()` | `.fillna()` 或 `.dropna()` |
| 重複值 | `.duplicated().sum()` | `.drop_duplicates()` |

## 四、上線量 = 0 快速排查表

| 步驟 | 檢查項目 | 命令 | 預期結果 |
|------|----------|------|----------|
| 1 | 派工量表有無對應 key？ | `df_派工量.columns` | 應包含可與上線量對應的欄位 |
| 2 | 上線量表的 key 欄位名稱 | `df_上線量.columns` | 通常是 `QP_Code` |
| 3 | 派工量的 key 欄位資料型別 | `df_派工量['key'].dtype` | 應與上線量一致 |
| 4 | 上線量的 key 欄位資料型別 | `df_上線量['key'].dtype` | 應與派工量一致 |
| 5 | 型別轉換後是否有匹配 | 統計重疊值數量 | > 90% 為正常 |
| 6 | merge 結果是否正確？ | 檢查 merge 後的列數 | 應 > 派工量原列數 |

**快速診斷程式碼：**

```python
# 診斷 1：檢查 key 欄位是否存在
print("派工量欄位:", df_派工量.columns.tolist())
print("上線量欄位:", df_上線量.columns.tolist())

# 診斷 2：檢查資料型別
print("派工量 key 型別:", df_派工量['ERP品號'].dtype)
print("上線量 key 型別:", df_上線量['QP_Code'].dtype)

# 診斷 3：轉換後進行 merge，確認覆蓋率
if df_派工量['ERP品號'].dtype != df_上線量['QP_Code'].dtype:
    df_派工量['ERP品號_str'] = df_派工量['ERP品號'].astype(str).str.strip()
    df_上線量['QP_Code_str'] = df_上線量['QP_Code'].astype(str).str.strip()

merge_result = df_派工量.merge(上線_統計, left_on='ERP品號_str', right_on='QP_Code_str', how='left')
覆蓋率 = (merge_result['上線量'].notna().sum()) / len(merge_result)
print(f"覆蓋率: {覆蓋率*100:.1f}%")
```

## 六、臨時救急指令

**上線量 = 0 一行快速診斷：**

```python
import pandas as pd
派 = pd.read_excel('file.xlsx', sheet_name='派工量(PQ)')
上 = pd.read_excel('file.xlsx', sheet_name='上線量(PQ)')
類 = pd.read_excel('file.xlsx', sheet_name='類型清單')

派合 = 派.merge(類[['替換前品項','ERP品號']], on='替換前品項', how='left')
派合['erp_str'] = 派合['ERP品號'].astype(str).str.strip()

上統 = 上.groupby('QP_Code').size().reset_index(name='上線量')
上統['qp_str'] = 上統['QP_Code'].astype(str).str.strip()

結果 = 派合.merge(上統, left_on='erp_str', right_on='qp_str', how='left')
print(f'覆蓋率: {(結果["上線量"].notna().sum())/len(結果)*100:.1f}%')
print(f'平均上線量: {結果["上線量"].mean():.0f}')
```
