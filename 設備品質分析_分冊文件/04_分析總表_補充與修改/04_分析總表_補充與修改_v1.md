## 第二節：已知問題與說明

### 問題：彙整總覽維護類型計數與彙整總表筆數不符

**現象：**
某 ERP品號 在彙整總表中有多筆資料，但分析總表的車機\_彙整總覽或鏡頭\_彙整總覽中，對應欄位（如「其他」）的計數比預期少。

**原因：**
工作表七（車機\_彙整總覽）篩選條件為「設備類型=車機 且 維護原因=訊號異常」；工作表八（鏡頭\_彙整總覽）篩選條件為「設備類型=鏡頭 且 維護原因=影像異常(鏡頭)」。同一 ERP品號 若存在不同維護原因的資料列（如「大餅車速異常」、「客戶要求」等），這些列會被篩選排除，不計入任何維護類型欄位。

**結論：此為預期行為，篩選條件正確，無需修改。**

**查驗範例：**

| 說明 | 內容 |
|------|------|
| ERP品號 | 1000123 |
| 彙整總表共 | 3 筆（維護原因：大餅車速異常×1、訊號異常×2） |
| 分析總表結果 | 失聯=2、其他=0（大餅車速異常那筆被篩選掉，符合設計） |

## 第三節：v3 修改覆蓋 — 已使用年限僅針對回廠過保數設備計算

> **本節覆蓋第一節中關於「已使用年限」的計算邏輯，以本節為最終版本。**

### 修改範圍

全部工作表（一至八）。

### 邏輯對比

| 版本 | 計算邏輯 |
|------|----------|
| v2（舊，已廢棄） | 依分組，對**所有**符合篩選條件的明細計算平均已使用年限 |
| **v3（現行）** | 依分組，**僅對被判定為回廠過保數的明細**計算平均已使用年限 |

### 回廠過保數判斷條件

符合以下**任一**條件的明細，視為回廠過保數：

| 條件 | 欄位 | 值 |
|------|------|----|
| 停產報廢 | 維修分類 | `D /停產報廢`（以 D 開頭） |
| 過保報廢 | 維修分類 | `E /過保報廢`（以 E 開頭） |
| 回廠報廢 | QC | `回廠報廢` |

### 各工作表行為（v3）

| 工作表 | 已使用年限欄位行為 |
|--------|------------------|
| 一：車機\_數量統計 | 回廠過保數明細的平均值；無過保記錄則顯示空白 |
| 二：鏡頭\_數量統計 | 同上 |
| 三：車機\_維修分類交叉 | 同上 |
| 四：鏡頭\_維修分類交叉 | 同上 |
| 五：車機\_維護類型交叉 | 同上 |
| 六：鏡頭\_維護類型交叉 | 同上 |
| 七：車機\_彙整總覽 | 同上 |
| 八：鏡頭\_彙整總覽 | 同上 |

### 進貨日欄位（不受 v3 影響）

> 工作表三至六的「進貨日」欄位邏輯**不變**，仍取每筆明細的原始值。
