# 冊 05：多期合併版 製作流程

> 本冊說明如何從「單季分析總表」產出「多期合併版分析總表」，供 quality-dashboard 進行同期（YoY）比較、月趨勢圖顯示，以及成本節省金額呈現。

---

## 第一節：多期合併版說明與結構

### 目的

單季分析總表只能顯示單一期間資料。多期合併版透過新增 `期間` 欄，讓多個季度（如 2025-Q1、2026-Q1）的資料並存於同一工作表，Dashboard 自動依期間分類顯示 KPI 與比較圖表。

### 工作表結構（v5，對應 v2 輸出格式）

| 工作表名稱 | 類型 | 說明 |
|-----------|------|------|
| 車機_彙整總覽 | 必要 | 原有工作表七，**新增第一欄「期間」** |
| 鏡頭_彙整總覽 | 必要 | 原有工作表八，**新增第一欄「期間」** |
| 車機_月趨勢 | 選填 | 新增工作表，提供月粒度資料供趨勢折線圖 |
| 鏡頭_月趨勢 | 選填 | 新增工作表，提供月粒度資料供趨勢折線圖 |
| **成本節省總覽** | **選填** | **新增工作表（v5），提供各期不送修節省維運金額明細（見第六節）** |
| 設備品質分析_彙整總表 | 保留 | 原有（v2 新增），來自各期單季分析總表，**合併時保留最新一期的版本** |

> **重要**：quality-dashboard 讀取 `車機_彙整總覽`、`鏡頭_彙整總覽`、`車機_月趨勢`、`鏡頭_月趨勢`、`成本節省總覽` 五張工作表。其餘工作表保留供人工審閱，不影響網站功能。

---

## 第二節：Step 1 — 準備各期單季分析總表

### 前提

每個期間（如 2025-Q1、2026-Q1）都需要一份完整的「單季分析總表」，依照冊 01、冊 03 的現行流程產出。

**單季分析總表命名規則：**

| 期間 | 對應資料庫檔案 | 產出分析總表 |
|------|--------------|------------|
| 2025-Q1 | `設備品質分析_資料庫_25_Q1.xlsm` | `設備品質分析_分析總表_25_Q1.xlsx` |
| 2026-Q1 | `設備品質分析_資料庫_26_Q1.xlsm` | `設備品質分析_分析總表_26_Q1.xlsx` |
| 2026-Q2 | `設備品質分析_資料庫_26_Q2.xlsm` | `設備品質分析_分析總表_26_Q2.xlsx` |

### 操作

1. 依照**冊 01「資料庫彙整操作步驟」**，從對應的 `設備品質分析_資料庫_{YY}_{Qn}.xlsm` 匯出原始資料：
   - 派工量：`品項完工年月` 篩選範圍
     - 2025-Q1：`2025-01` 至 `2025-03`
     - 2026-Q1：`2026-01` 至 `2026-03`
     - 2026-Q2：`2026-01` 至 `2026-06`（累積制）
   - 維修量：`輸入年月` 篩選範圍（同上）
   - 報廢量：依完成日期篩選（同上）
   - 上線量、進貨日：不受期間限制，取全量

2. 跑資料庫彙整流程（冊 01 Step 1–8），產出該期間的 `設備品質分析_彙整總表.xlsx`

3. 跑分析總表流程（冊 03），產出 `設備品質分析_分析總表_{YY}_{Qn}.xlsx`
   - 確認輸出檔內含三個工作表（車機_彙整總覽、鏡頭_彙整總覽、設備品質分析_彙整總表）

> **中間工作檔說明**：`設備品質分析_彙整總表_{YY}_{Qn}.xlsx` 與 `設備品質分析_分析總表_{YY}_{Qn}.xlsx` 均為中間工作檔，其資料已完整嵌入合併版中。合併版（`設備品質分析_分析總表.xlsx`）產出後，這些單期檔案不需另行保留，可視需要自行決定是否刪除。

## 第三節：Step 2 — 在彙整總覽工作表加入「期間」欄

### 適用工作表

- `車機_彙整總覽`（原工作表七）
- `鏡頭_彙整總覽`（原工作表八）

### 操作步驟

1. 開啟各期分析總表 Excel
2. 切換到 `車機_彙整總覽` 工作表
3. 在第 A 欄（最左欄）**插入新欄**：
   - 右鍵點選欄 A 標頭 → 選「插入」
4. 在 A1 儲存格填入欄位名稱：`期間`
5. 設定 A1 樣式（對齊現有標頭）：
   - 底色：`D9E1F2`（淡藍色，與 B1 以右標頭相同）
   - 字型：微軟正黑體，粗體
   - 對齊：置中
6. 從 A2 開始，對所有資料列填入該期間代碼，例如：
   - 25_Q1 的分析總表 → 填入 `2025-Q1`
   - 26_Q1 的分析總表 → 填入 `2026-Q1`
   - 可先在 A2 填入值，再選取 A2，向下填滿至最後一列
7. 資料列樣式（對齊現有欄位）：
   - **底色：無**（同其他資料欄位，不可有任何底色）
   - 字型：微軟正黑體，一般（非粗體），字色黑
8. 對 `鏡頭_彙整總覽` 重複步驟 2–7

> ✅ 格式確認標準：A欄標頭底色 = B欄標頭底色（`D9E1F2`）；A欄資料列底色 = B欄資料列底色（無底色）。

## 第四節：Step 3 — 合併多期資料

### 目標

將多個期間的 `車機_彙整總覽` 資料，合併到同一工作表中（`鏡頭_彙整總覽` 同理）。

---

### 📋 執行紀錄參考（2026-04-29）

**合併對象：**

| 來源檔案 | 期間 | 車機筆數 | 鏡頭筆數 |
|----------|------|---------|---------|
| `設備品質分析_分析總表_26_Q1.xlsx` | 2026-Q1 | 57 筆 | 31 筆 |
| `設備品質分析_分析總表_25_Q1.xlsx` | 2025-Q1 | 56 筆 | 29 筆 |

**合併結果：**

| 工作表 | 合計筆數 | 期間分布 |
|--------|---------|---------|
| 車機_彙整總覽 | 113 筆 | 2026-Q1: 57 筆 / 2025-Q1: 56 筆 |
| 鏡頭_彙整總覽 | 60 筆  | 2026-Q1: 31 筆 / 2025-Q1: 29 筆 |

---

### 手動操作步驟（下次新期間合併時參考）

1. **以最新一期的分析總表為基礎**（例如 `設備品質分析_分析總表_26_Q1.xlsx`），另存新檔：
   ```
   設備品質分析_分析總表.xlsx
   ```

2. 確認此檔的 `車機_彙整總覽` 已完成 Step 2（已有「期間」欄，A欄值為 `2026-Q1`）

3. 開啟舊期分析總表（例如 `設備品質分析_分析總表_25_Q1.xlsx`）：
   - 確認其 `車機_彙整總覽` 也已完成 Step 2（A欄值為 `2025-Q1`）
   - 選取 A2 到最後一列最後一欄（含「期間」欄在內的全部資料列）
   - 複製（Ctrl+C）

4. 切回合併檔案的 `車機_彙整總覽`：
   - 點選現有資料的**最後一列下方的空白列**（即緊接著最後一筆資料的下一列）
   - 貼上（Ctrl+V）

5. 確認貼入後：
   - A欄值為舊期代碼（`2025-Q1`）
   - 欄位順序與現有資料一致
   - 無多餘空白列或欄位錯位

6. 對 `鏡頭_彙整總覽` 重複步驟 3–5

7. **處理 `設備品質分析_彙整總表` 工作表**：
   - 保留最新一期（例如 `2026-Q1`）的 `設備品質分析_彙整總表` 工作表不變
   - 若需保留所有期間的原始明細，可將舊期彙整總表資料也追加貼入（選填）

> **注意**：若要加入第三期（如 2026-Q2），重複步驟 3–5 即可，不需改動工作表結構。

## 第五節：Step 4 — 建立月趨勢工作表

月趨勢工作表提供月粒度資料，讓 Dashboard 繪製「每月回廠量／不良數」折線圖並進行同期比較。

### 工作表規格

兩張工作表欄位結構相同，共 **16 欄**（v4：新增「廠商」欄），差異只在第 12–16 欄的故障分類名稱：

| 欄號 | 車機_月趨勢 | 鏡頭_月趨勢 | 格式 |
|------|-----------|-----------|------|
| 1 | 期間 | 期間 | 文字，如 `2025-Q1` |
| 2 | 年月 | 年月 | 文字，如 `2025-01` |
| 3 | 類型 | 類型 | 廠牌型號（同彙整總覽「類型」欄） |
| 4 | **廠商** | **廠商** | 文字（v4 新增，來自彙整總表廠商欄） |
| 5 | ERP品號 | ERP品號 | 數值或文字（可為空） |
| 6 | 品名 | 品名 | 文字（可為空） |
| 7 | 上線量 | 上線量 | 整數 |
| 8 | 回廠量 | 回廠量 | 整數 |
| 9 | 不良品數 | 不良品數 | 整數 |
| 10 | 良品數 | 良品數 | 整數 |
| 11 | 過保數 | 過保數 | 整數 |
| 12 | **失聯** | **黑畫面** | 整數 |
| 13 | **定位不良** | **進水/模糊** | 整數 |
| 14 | **訊號異常** | **水波紋** | 整數 |
| 15 | **AB點** | **時有時無** | 整數 |
| 16 | **其他** | **其他** | 整數 |

> ⚠️ **常見錯誤**：若用車機月趨勢工作表複製產生鏡頭月趨勢，**必須手動修改第 12–16 欄的標頭名稱**，否則故障類型欄位將顯示車機名稱（失聯、定位不良等），導致故障趨勢分析錯誤。

---

### 資料來源（v2 更新）

月趨勢資料從各期分析總表內嵌的 **`設備品質分析_彙整總表`** 工作表（工作表九）計算，而非另開資料庫檔案。

**做法：** 讀取各期 `設備品質分析_分析總表_{YY}_{Qn}.xlsx` → `設備品質分析_彙整總表` 工作表，依 `品項完工日期`（取 YYYY-MM）分別篩選各月份，以相同的類型分組邏輯統計各指標，每個「類型 × 年月 × 期間」填一列。

**分組欄位：** `期間`、`年月`（從品項完工日期取）、`廠牌型號`（→類型）、`廠商`、`ERP品號`、`替換前品項`（→品名）

**篩選條件：**
- 車機：設備類型 = `車機` ＋ 維護原因 = `訊號異常`
- 鏡頭：設備類型 = `鏡頭` ＋ 維護原因 = `影像異常(鏡頭)`

**各欄計算邏輯：**

| 欄位 | 計算方式 |
|------|----------|
| 上線量 | 該組第一個非空值（同 ERP品號 對應固定值） |
| 回廠量 | 該組筆數 |
| 不良品數 | 維修分類以 G、X 開頭，或 = 維修換貨＋換貨條碼 的筆數 |
| 良品數 | QC ∈ {廠商檢測正常, 回廠QC, 其他} 的筆數 |
| 過保數 | 維修分類以 D、E 開頭，或 QC = 回廠報廢 的筆數 |

> **月趨勢刻意不含「未歸類數」**（2026-07-24 補充說明）：00_規則定義.md 規則G（現行 v8）在良品/不良品/過保之外，另有第四桶「未歸類」（= H/人為報廢、V/已完修 人為、QC=其他(未過)，見 07冊 §7）。車機_彙整總覽／鏡頭_彙整總覽（冊03 v7）已收錄「未歸類數」，但**月趨勢工作表刻意不跟進**——月趨勢的用途單純是月粒度的回廠量／不良品／良品／過保趨勢折線圖，不要求四桶必須加總＝回廠量，所以上面三欄（不良品數/良品數/過保數）加總會小於回廠量，這是預期範圍，不是漏欄。若之後需要月趨勢也能對帳到 100%，需另外決議是否新增「未歸類數」欄（會變成 17 欄）。
| 失聯（車機）| 維護類型 = 失聯 的筆數 |
| 定位不良（車機）| 維護類型 = 定位不良 的筆數 |
| 訊號異常（車機）| 維護類型 = 訊號異常 的筆數 |
| AB點（車機）| 維護類型 = AB對調 的筆數 |
| 其他（車機）| 不屬於以上四類的筆數 |
| 黑畫面（鏡頭）| 維護類型 = 黑畫面 的筆數 |
| 進水/模糊（鏡頭）| 維護類型 = 進水/模糊 的筆數 |
| 水波紋（鏡頭）| 維護類型 = 水波紋 的筆數 |
| 時有時無（鏡頭）| 維護類型 = 時有時無 的筆數 |
| 其他（鏡頭）| 不屬於以上四類的筆數 |

**排序：** 期間降冪（最新在前）→ 年月升冪 → 類型升冪 → ERP品號升冪

> ⚠️ **重要**：務必對 DataFrame 執行 `reset_index(drop=True)` 再逐列寫入 Excel，否則會以原始 DataFrame index 作為列號，造成兩期資料中間出現大量空白列。

```python
import pandas as pd

# 讀取各期彙整總表（從嵌入工作表讀取）
df_25 = pd.read_excel('設備品質分析_分析總表_25_Q1.xlsx',
                      sheet_name='設備品質分析_彙整總表', engine='openpyxl')
df_26 = pd.read_excel('設備品質分析_分析總表_26_Q1.xlsx',
                      sheet_name='設備品質分析_彙整總表', engine='openpyxl')

# 標記期間
df_25['期間'] = '2025-Q1'
df_26['期間'] = '2026-Q1'

# 合併後依 品項完工日期 分組計算（取 YYYY-MM）
df_all = pd.concat([df_25, df_26], ignore_index=True)
df_all['年月'] = pd.to_datetime(df_all['品項完工日期']).dt.strftime('%Y-%m')
```

## 第六節：Step 5 — 計算成本節省總覽

### 前提條件

- `成本參數設定.xlsx` 已建立並放置於**同一工作資料夾**（見冊 06 第二節）
- 各期單季分析總表已完成，且包含 `設備品質分析_彙整總表` 工作表
- 多期合併版 `設備品質分析_分析總表.xlsx` 已完成 Step 3（合併多期資料）

### 目標

從各期彙整總表中篩選「維修分類 = 不送修」的記錄，依廠牌型號計算節省維運金額，寫入多期合併版的 `成本節省總覽` 工作表。涵蓋車機、鏡頭、配件、耗材全四類設備。

> **工作表欄位規格** 詳見冊 03 工作表十；**成本參數說明** 詳見冊 06。

### Python 腳本

```python
import pandas as pd
from openpyxl import load_workbook
from openpyxl.styles import Font, PatternFill, Alignment
from openpyxl.utils import get_column_letter

# ── 0. 設定期別對照（每次新增期別時更新此清單）────────────────────
PERIODS = [
    ('2025-Q1', '設備品質分析_分析總表_25_Q1.xlsx'),
    ('2026-Q1', '設備品質分析_分析總表_26_Q1.xlsx'),
    # 新增期別時在此追加，例如：
    # ('2026-Q2', '設備品質分析_分析總表_26_Q2.xlsx'),
]
OUTPUT_FILE    = '設備品質分析_分析總表.xlsx'   # 多期合併版（Step 3 已產出）
COST_PARAM_FILE = '成本參數設定.xlsx'           # 成本參數設定檔（冊 06）

# ── 1. 讀取成本參數 ──────────────────────────────────────────────
df_cost   = pd.read_excel(COST_PARAM_FILE, sheet_name='成本預估')
df_params = pd.read_excel(COST_PARAM_FILE, sheet_name='系統參數', index_col='參數名稱')

shipping_cost = float(df_params.loc['每件運費', '值'])   # 預設 130
labor_minutes = float(df_params.loc['每件工時', '值'])   # 預設 3
hourly_rate   = float(df_params.loc['時薪',    '值'])    # 預設 196

# ── 2. 計算各廠牌型號整新單價合計（Option A：加總同廠牌型號全部操作）
unit_cost = (
    df_cost
    .groupby(['設備類型', '廠牌型號'])['整新單價']
    .sum()
    .reset_index()
    .rename(columns={'整新單價': '整新單價合計'})
)

# ── 3. 讀取各期彙整總表，標記期間後合併 ─────────────────────────
dfs = []
for period_code, filename in PERIODS:
    df = pd.read_excel(filename, sheet_name='設備品質分析_彙整總表')
    df['期間'] = period_code
    dfs.append(df)

df_all = pd.concat(dfs, ignore_index=True)

# ── 4. 篩選不送修記錄（涵蓋全設備類型：車機、鏡頭、配件、耗材）──
df_nosend = df_all[df_all['維修分類'] == '不送修'].copy()

# ── 5. 分組計算不送修數量 ────────────────────────────────────────
df_grouped = (
    df_nosend
    .groupby(['期間', '設備類型', '廠牌型號', '廠商'])
    .size()
    .reset_index(name='不送修數量')
)

# ── 6. Join 整新單價合計 ─────────────────────────────────────────
df_result = df_grouped.merge(unit_cost, on=['設備類型', '廠牌型號'], how='left')
df_result['整新單價合計'] = df_result['整新單價合計'].fillna(0).astype(int)

# ── 7. 計算節省金額與工時 ────────────────────────────────────────
df_result['節省金額合計'] = (
    (df_result['整新單價合計'] + shipping_cost) * df_result['不送修數量']
).astype(int)

df_result['耗費工時_分鐘'] = (
    labor_minutes * df_result['不送修數量']
).astype(int)

df_result['工時成本_元'] = (
    df_result['耗費工時_分鐘'] * hourly_rate / 60
).round(0).astype(int)

# ── 8. 排序：期間降冪 → 設備類型升冪 → 廠牌型號升冪 ─────────────
df_result = (
    df_result
    .sort_values(['期間', '設備類型', '廠牌型號'],
                 ascending=[False, True, True])
    .reset_index(drop=True)
)

df_result = df_result[[
    '期間', '設備類型', '廠牌型號', '廠商',
    '不送修數量', '整新單價合計',
    '節省金額合計', '耗費工時_分鐘', '工時成本_元'
]]

# ── 9. 寫入多期合併版分析總表 ────────────────────────────────────
wb = load_workbook(OUTPUT_FILE)

if '成本節省總覽' in wb.sheetnames:
    del wb['成本節省總覽']

ws = wb.create_sheet('成本節省總覽')

header_fill  = PatternFill('solid', fgColor='D9E1F2')
header_font  = Font(name='微軟正黑體', bold=True)
header_align = Alignment(horizontal='center')
data_font    = Font(name='微軟正黑體')
data_align   = Alignment(horizontal='left')

for col_idx, col_name in enumerate(df_result.columns, 1):
    cell = ws.cell(row=1, column=col_idx, value=col_name)
    cell.fill      = header_fill
    cell.font      = header_font
    cell.alignment = header_align

for row_idx, row in df_result.iterrows():
    for col_idx, value in enumerate(row, 1):
        cell = ws.cell(row=row_idx + 2, column=col_idx, value=value)
        cell.font      = data_font
        cell.alignment = data_align

for col in ws.columns:
    max_len = max(len(str(cell.value or '')) for cell in col)
    ws.column_dimensions[get_column_letter(col[0].column)].width = max_len + 4

wb.save(OUTPUT_FILE)
print(f'成本節省總覽 寫入完成：{len(df_result)} 筆')

# ── 驗算提示 ─────────────────────────────────────────────────────
unmatched = df_result[df_result['整新單價合計'] == 0]
if not unmatched.empty:
    print('\n⚠️  以下廠牌型號在成本預估中找不到對應（整新單價合計=0）：')
    print(unmatched[['設備類型', '廠牌型號', '不送修數量']].to_string(index=False))
    print('請補充 成本參數設定.xlsx → 成本預估 後重跑。')
```

### 注意事項

- `PERIODS` 清單需與實際期別對應，每新增一期就在清單中追加一筆
- 整新單價合計為 0 的列代表該廠牌型號未在成本預估中設定，腳本會在終端機列出警告
- 腳本每次執行時會先刪除舊的 `成本節省總覽` 工作表再重建，重複執行安全

## 附錄：格式規範與常見錯誤

### 期間代碼命名規則

| 情境 | 期間代碼 | 說明 |
|------|----------|------|
| 2025年第一季（1~3月） | `2025-Q1` | |
| 2026年第一季（1~3月） | `2026-Q1` | |
| 2026年上半年（1~6月） | `2026-Q2` | 若採累積制，Q2代表Q1+Q2 |
| 2026年第二季（僅4~6月） | `2026-Q2only` | 若採單季制，需統一命名規則 |

> **建議**：統一採累積制（Q2 = 上半年），與業務報告習慣一致。

### 分析總表檔案命名規則（v2）

| 類型 | 命名格式 | 說明 |
|------|----------|------|
| 單季分析總表 | `設備品質分析_分析總表_{YY}_{Qn}.xlsx` | 例：`設備品質分析_分析總表_25_Q1.xlsx` |
| 多期合併版（最終） | `設備品質分析_分析總表.xlsx` | 供 quality-dashboard 上傳 |

### 常見錯誤

| 錯誤類型 | 症狀 | 解決方式 |
|----------|------|----------|
| 期間欄有底色 | A欄資料列顏色與其他欄不同 | 選取資料列 → 清除底色 |
| 期間代碼格式不一致 | 如 `2026Q1`（無連字號）vs `2026-Q1` | 統一使用 `YYYY-Qn` 格式 |
| 月趨勢年月格式錯誤 | 如 `202601` 而非 `2026-01` | 統一使用 `YYYY-MM` 格式 |
| 貼上後欄位錯位 | 舊期資料欄位與新期不對齊 | 確認兩份來源檔的欄位順序一致 |
| 空白列導致圖表斷線 | 月趨勢折線圖中斷 | 刪除資料中間的空白列 |
| 月趨勢鏡頭欄位名稱錯誤 | 鏡頭月趨勢顯示車機故障名稱 | 手動修改第12–16欄標頭為鏡頭名稱 |
| 成本節省總覽無資料 | 工作表空白或不存在 | 確認 `成本參數設定.xlsx` 存在且路徑正確後重跑 Step 5 |
| 整新單價合計全為 0 | 節省金額只計運費 | 確認 `成本參數設定.xlsx` → `成本預估` 的廠牌型號格式與彙整總表一致 |
