# 冊 01：資料庫彙整 操作步驟

## 來源與輸出

| 項目 | 說明 |
|------|------|
| 來源檔案 | `設備品質分析_資料庫_{YY}_{Qn}.xlsm`（例：`設備品質分析_資料庫_25_Q1.xlsm`，含八個工作表） |
| 中間產出 | `設備品質分析_彙整總表.xlsx`（作業用暫存檔，供冊 03 讀取） |
| 最終嵌入 | 彙整總表資料最終以工作表 `設備品質分析_彙整總表` 形式嵌入 `設備品質分析_分析總表_{YY}_{Qn}.xlsx`（見冊 03） |

### 資料庫工作表清單（共八個）

| Sheet Index | 工作表名稱 | 用途 |
|-------------|-----------|------|
| 0 | 上線量(PQ) | 統計各 ERP品號 上線數量 |
| 1 | 派工量(PQ) | 主表，提供品項完工日期、替換前品項、條碼等 |
| 2 | 維修量(PQ) | 提供維修資訊（完成原因）；以條碼 merge |
| 3 | 報廢量(PQ) | 提供報廢資訊（報廢狀態、報廢原因）；以條碼 merge |
| 4 | 進貨日(PQ) | 提供首次出現時間（進貨日）；以條碼 merge |
| 5 | 類型清單 | 提供 ERP品號、設備類型、廠牌型號、**廠商**；以替換前品項 merge |
| 6 | 維修分類 | 維修分類代碼對照（參照用，不直接參與 merge） |
| 7 | 品號對照表 | 提供品號 ↔ 主供應商名稱對照；廠商備援來源 |

## Step 1：字體設定

所有工作表字體改為「微軟正黑體」後再進行彙整。

---

## Step 2：資料關聯邏輯

以「派工量(PQ)」為主表，進行以下關聯：

| 關聯目的 | 主表欄位 | 對應表 | 對應欄位 | 帶入欄位 |
|----------|----------|--------|----------|---------|
| 帶入維修資料 | 替換前品項條碼 | 維修量(PQ) | 條碼 | 完成原因 |
| 帶入報廢資料 | 替換前品項條碼 | 報廢量(PQ) | 條碼 | 報廢單狀態、報廢原因 |
| 帶入設備類型與廠商 | 替換前品項 | 類型清單 | 替換前品項 | ERP品號、設備類型、廠牌型號、**廠商** |

```python
# Step 2：合併類型清單，帶入設備類型、廠牌型號、ERP品號、廠商
結果 = 派工量.merge(
    類型清單[['替換前品項', 'ERP品號', '設備類型', '廠牌型號', '廠商']],
    on='替換前品項',
    how='left'
)
```

---

## Step 2.5：確認無法對應 ERP品號 的品項（⚠️ 必須在產出前執行）

完成 Step 2 merge 後，**立即**檢查類型清單中找不到對應的品項，並在產出任何檔案之前先回報給使用者確認。

### 檢查方式

找出 merge 後 `ERP品號` 為空的所有不重複 `替換前品項`，列出品項名稱與筆數：

```python
missing = 結果[結果['ERP品號'].isna()]['替換前品項'].dropna().unique()
for item in sorted(missing):
    cnt = (結果['替換前品項'] == item).sum()
    print(f"  {item}（{cnt} 筆）")
```

### 確認流程

1. 列出所有找不到 ERP品號 的品項，**等待使用者回覆**
2. **若使用者提供 ERP品號** → 更新類型清單後，重新執行 Step 2 merge，再繼續往下
3. **若使用者回覆不需要** → 直接繼續往下（這些品項設備類型及廠商欄位為空，不會計入統計）

> ⚠️ **禁止**：尚未取得使用者確認前，不可產出彙整總表或分析總表。

## Step 2.7：廠商備援填入（v3 新增）

完成 Step 2.5 確認後，針對「廠商欄位為空但 ERP品號 有值」的記錄，從品號對照表補入主供應商名稱。

```python
# Step 2.7：讀取品號對照表
品號對照表 = pd.read_excel(
    '設備品質分析_資料庫_{YY}_{Qn}.xlsm',
    sheet_name=7,   # index 7（品號對照表）
    engine='openpyxl'
)
# 建立 ERP品號 → 主供應商名稱 對照
品號對照表['品號_str'] = 品號對照表['品號'].astype(str).str.strip()
廠商備援 = 品號對照表.set_index('品號_str')['主供應商名稱']

# 備援填入：廠商為空 且 ERP品號 有值
結果['ERP品號_str'] = 結果['ERP品號'].astype(str).str.strip()
mask = 結果['廠商'].isna() & 結果['ERP品號'].notna()
結果.loc[mask, '廠商'] = 結果.loc[mask, 'ERP品號_str'].map(廠商備援)
結果 = 結果.drop(columns=['ERP品號_str'])
```

## Step 4：新增「上線量」欄位

- **來源**：上線量(PQ) 工作表
- **邏輯**：依 ERP品號 統計各品號上線量，對應填入主表 ERP品號 欄位

> ⚠️ 注意：上線量表的 Key 欄位為 `QP_Code`（字串型），派工量表無直接 ERP品號 欄位，需先與類型清單 merge 取得。詳見冊 02 問題排查。

```python
# 1. 統計上線量並確保資料型別一致
上線_統計 = 上線量.groupby('QP_Code').size()
結果['ERP品號_str'] = 結果['ERP品號'].astype(str).str.strip()

# 2. 使用轉換後的字串進行 merge
結果 = 結果.merge(上線_統計.rename('上線量'), left_on='ERP品號_str', right_index=True, how='left')
結果 = 結果.drop(columns=['ERP品號_str'])
```

## Step 7：新增「進貨日」與「已使用年限」欄位

### 欄位說明

| 欄位名稱 | 說明 |
|----------|------|
| 進貨日 | 透過「替換前品項條碼」對應 `進貨日(PQ)` 工作表的「條碼」欄位，取得對應的「首次出現時間」 |
| 已使用年限 | `(品項完工日期 - 進貨日) / 365`，取小數點第一位 |

```python
import pandas as pd

# Step 7-1：讀取進貨日資料
df_j = pd.read_excel('設備品質分析_資料庫_{YY}_{Qn}.xlsm', sheet_name=4, engine='openpyxl')

# Step 7-2：建立條碼對應表
lookup = df_j.set_index(df_j['條碼'].str.strip())['首次出現時間']

# Step 7-3：新增「進貨日」欄位
結果['進貨日'] = 結果['替換前品項條碼'].map(
    lambda x: lookup.get(str(x).strip()) if pd.notna(x) else None
)

# Step 7-4：新增「已使用年限」欄位
結果['品項完工日期_dt'] = pd.to_datetime(結果['品項完工日期'], errors='coerce')
結果['進貨日_dt'] = pd.to_datetime(結果['進貨日'], errors='coerce')
結果['已使用年限'] = ((結果['品項完工日期_dt'] - 結果['進貨日_dt']).dt.days / 365).round(1)
結果['進貨日'] = 結果['進貨日_dt'].dt.strftime('%Y-%m-%d')
結果 = 結果.drop(columns=['品項完工日期_dt', '進貨日_dt'])
```
