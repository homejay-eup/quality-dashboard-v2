# 冊 01：資料庫彙整 操作步驟

## 來源與輸出

| 項目 | 說明 |
|------|------|
| 來源檔案 | `設備品質分析_資料庫_{YY}_{Qn}.xlsm`（例：`設備品質分析_資料庫_25_Q1.xlsm`，含七個工作表） |
| 中間產出 | `設備品質分析_彙整總表.xlsx`（作業用暫存檔，供冊 03 讀取） |
| 最終嵌入 | 彙整總表資料最終以工作表 `設備品質分析_彙整總表` 形式嵌入 `設備品質分析_分析總表_{YY}_{Qn}.xlsx`（見冊 03） |

### 資料庫工作表清單（共七個）

| Sheet Index | 工作表名稱 | 用途 |
|-------------|-----------|------|
| 0 | 上線量(PQ) | 統計各 ERP品號 上線數量 |
| 1 | 派工量(PQ) | 主表，提供品項完工日期、替換前品項、條碼等 |
| 2 | 維修量(PQ) | 提供維修資訊（完成原因）；以條碼 merge |
| 3 | 報廢量(PQ) | 提供報廢資訊（報廢狀態、報廢原因）；以條碼 merge |
| 4 | 進貨日(PQ) | 提供首次出現時間（進貨日）；以條碼 merge |
| 5 | 類型清單 | 提供 ERP品號、設備類型、廠牌型號；以替換前品項 merge |
| 6 | 維修分類 | 維修分類代碼對照（參照用，不直接參與 merge） |

## Step 1：字體設定

所有工作表字體改為「微軟正黑體」後再進行彙整。

## Step 2：資料關聯邏輯

以「派工量(PQ)」為主表，進行以下關聯：

| 關聯目的 | 主表欄位 | 對應表 | 對應欄位 |
|----------|----------|--------|----------|
| 帶入維修資料 | 替換前品項條碼 | 維修量(PQ) | 條碼 |
| 帶入報廢資料 | 替換前品項條碼 | 報廢量(PQ) | 條碼 |
| 帶入設備類型 | 替換前品項 | 類型清單 | 替換前品項 |

## Step 2.5：確認無法對應 ERP品號 的品項（⚠️ 必須在產出前執行）

完成 Step 2 merge 後，**立即**檢查類型清單中找不到對應的品項，並在產出任何檔案之前先回報給使用者確認。

### 檢查方式

找出 merge 後 `ERP品號` 為空的所有不重複 `替換前品項`，列出品項名稱與筆數：

```python
missing = df[df['ERP品號'].isna()]['替換前品項'].dropna().unique()
for item in sorted(missing):
    cnt = (df['替換前品項'] == item).sum()
    print(f"  {item}（{cnt} 筆）")
```

### 確認流程

1. 列出所有找不到 ERP品號 的品項，**等待使用者回覆**
2. **若使用者提供 ERP品號** → 更新類型清單後，重新執行 Step 2 merge，再繼續往下
3. **若使用者回覆不需要** → 直接繼續往下（這些品項設備類型欄位為空，不會計入統計）

> ⚠️ **禁止**：尚未取得使用者確認前，不可產出彙整總表或分析總表。

## Step 4：新增「上線量」欄位

- **來源**：上線量(PQ) 工作表
- **邏輯**：依 ERP品號 統計各品號上線量，對應填入主表 ERP品號 欄位

> ⚠️ 注意：上線量表的 Key 欄位為 `QP_Code`（字串型），派工量表無直接 ERP品號 欄位，需先與類型清單 merge 取得。詳見冊 02 問題排查。

```python
# 1. 先合併派工量與類型清單，取得 ERP品號
結果 = 派工量.merge(類型清單, on='替換前品項', how='left')

# 2. 統計上線量並確保資料型別一致
上線_統計 = 上線量.groupby('QP_Code').size()
結果['ERP品號_str'] = 結果['ERP品號'].astype(str).str.strip()

# 3. 使用轉換後的字串進行 merge
結果 = 結果.merge(上線_統計, left_on='ERP品號_str', right_on='QP_Code', how='left')
```

## Step 7：新增「進貨日」與「已使用年限」欄位

### 欄位說明

| 欄位名稱 | 說明 |
|----------|------|
| 進貨日 | 透過「替換前品項條碼」對應 `進貨日(PQ)` 工作表的「條碼」欄位，取得對應的「首次出現時間」 |
| 已使用年限 | `(品項完工日期 - 進貨日) / 365`，取小數點第一位 |

### 資料來源對應

**進貨日欄位**

| 項目 | 說明 |
|------|------|
| 來源工作表 | `設備品質分析_資料庫_{YY}_{Qn}.xlsm` → `進貨日(PQ)`（sheet index 4） |
| 對應 Key（主表） | 彙整總表 → `替換前品項條碼` |
| 對應 Key（參照表） | `進貨日(PQ)` → `條碼` |
| 帶入欄位 | `進貨日(PQ)` → `首次出現時間` |
| 對應邏輯 | 字串比對（需 `.str.strip()` 去除空白） |

**已使用年限欄位**

| 項目 | 說明 |
|------|------|
| 計算公式 | `(品項完工日期 - 進貨日) / 365` |
| 若進貨日為空 | 已使用年限也為空（無法計算） |
| 結果為負數 | 代表資料異常，需人工確認 |

### 執行程式碼

```python
import pandas as pd

# Step 7-1：讀取資料
df_out = pd.read_excel('設備品質分析_彙整總表.xlsx', engine='openpyxl')
df_j = pd.read_excel('設備品質分析_資料庫_{YY}_{Qn}.xlsm', sheet_name=4, engine='openpyxl')

# Step 7-2：建立條碼對應表
lookup = df_j.set_index(df_j['條碼'].str.strip())['首次出現時間']

# Step 7-3：新增「進貨日」欄位
df_out['進貨日'] = df_out['替換前品項條碼'].map(
    lambda x: lookup.get(str(x).strip()) if pd.notna(x) else None
)

# Step 7-4：新增「已使用年限」欄位
df_out['品項完工日期_dt'] = pd.to_datetime(df_out['品項完工日期'], errors='coerce')
df_out['進貨日_dt'] = pd.to_datetime(df_out['進貨日'], errors='coerce')
df_out['已使用年限'] = ((df_out['品項完工日期_dt'] - df_out['進貨日_dt']).dt.days / 365).round(1)

# 日期欄位格式化回字串
df_out['進貨日'] = df_out['進貨日_dt'].dt.strftime('%Y-%m-%d')
df_out = df_out.drop(columns=['品項完工日期_dt', '進貨日_dt'])

# Step 7-5：寫入 Excel（保留原有格式）
from openpyxl import load_workbook
from openpyxl.styles import Font, Alignment
import copy

wb = load_workbook('設備品質分析_彙整總表_備份.xlsx')
ws = wb.active

header_font = Font(name='微軟正黑體', size=11)
header_align = Alignment(horizontal='center')
data_font = Font(name='微軟正黑體', size=11)
data_align_center = Alignment(horizontal='center')

# 新增標題（欄18 = 進貨日，欄19 = 已使用年限）
for col, name in [(18, '進貨日'), (19, '已使用年限')]:
    cell = ws.cell(row=1, column=col, value=name)
    cell.font = header_font
    cell.alignment = header_align

# 填入資料
jinghuo_vals = df_out['進貨日'].tolist()
nianxian_vals = df_out['已使用年限'].tolist()

for row_idx, (j_val, n_val) in enumerate(zip(jinghuo_vals, nianxian_vals), start=2):
    c18 = ws.cell(row=row_idx, column=18)
    c18.value = j_val if pd.notna(j_val) and j_val != 'NaT' else None
    c18.font = copy.copy(data_font)
    c18.alignment = copy.copy(data_align_center)

    c19 = ws.cell(row=row_idx, column=19)
    c19.value = float(n_val) if pd.notna(n_val) else None
    c19.font = copy.copy(data_font)
    c19.alignment = copy.copy(data_align_center)

wb.save('設備品質分析_彙整總表.xlsx')
```

### 注意事項

| 陷阱 | 說明 |
|------|------|
| 條碼格式差異 | `進貨日(PQ).條碼` 可能含前導零，比對前務必 `.str.strip()` |
| 工作表索引 | `進貨日(PQ)` 為第 5 個工作表（`sheet_name=4`），若順序異動需重新確認 |

## Step 8：新增「QC」欄位

根據「維修分類」與「報廢原因」判斷（依優先順序）：

| QC 值 | 條件 |
|-------|------|
| 廠商檢測正常 | 維修分類 = O /測試正常 |
| 廠商完修 | 維修分類 = X /已完修 |
| 廠商完修 | 維修分類 = V /已完修 人為 |
| 廠商完修 | 維修分類 = 維修換貨＋換貨條碼 |
| 廠商報廢 | 維修分類 = E /過保報廢 |
| 廠商報廢 | 維修分類 = G /評估後退修 |
| 廠商報廢 | 維修分類 = D /停產報廢 |
| 廠商報廢 | 維修分類 = H /人為報廢 |
| 回廠其他 | 維修分類 = 無維修資訊 且 報廢原因不為空白 且 設備類型是鏡頭 且 已使用年限 < 1年 |
| 回廠其他 | 維修分類 = 無維修資訊 且 報廢原因不為空白 且 設備類型是車機 且 已使用年限 < 3年 |
| 回廠報廢 | 維修分類 = 無維修資訊 且 報廢原因不為空白 |
| 回廠QC | 維修分類 = 不送修 且 報廢原因為空白 |
| 其他 | 維修分類 = 無維修資訊 且 報廢原因為空白 |
