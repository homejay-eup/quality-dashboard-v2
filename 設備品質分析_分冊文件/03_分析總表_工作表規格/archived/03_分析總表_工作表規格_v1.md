## 工作表三：車機\_維修分類交叉

**篩選條件：**
- 設備類型 = 車機
- 維護原因 = 訊號異常

**樞紐分析表結構：**

| 區域 | 欄位 |
|------|------|
| 列標籤（Row Fields） | 類型 → ERP品號 → 替換前品項 |
| 欄標籤（Column Fields） | 維修分類 |
| 數值區域（Values） | 計數（Count） |
| 最後一欄 | 總計 |

**附加欄位：**

| 欄位名稱 | 來源 |
|----------|------|
| 進貨日 | 每筆明細各自帶入原始值（來自彙整總表）【v2，邏輯不變】 |
| 已使用年限 | 該分組回廠過保數明細的平均已使用年限（無過保記錄則空白）【v3】 |

**輸出格式：** 依分組展開，各維修分類在欄位上橫向展開，最右欄為總計。

| 欄位 | 來源／計算方式 |
|------|--------------|
| 期間 | 期間代碼，格式 `YYYY-Qn`，如 `2026-Q1`（**v4 新增，位於第一欄 A 欄**） |
| 類型 | 廠牌型號 |
| ERP品號 | ERP品號 |

| 回廠過保數 | D + E + 回廠報廢 的筆數加總 |
| 回廠人為數 | H /人為報廢 的筆數 |
| D /停產報廢 | 維修分類 = D 的筆數 |
| E /過保報廢 | 維修分類 = E 的筆數 |
| G /評估後退修 | 維修分類 = G 的筆數 |
| H /人為報廢 | 維修分類 = H 的筆數 |
| O /測試正常 | 維修分類 = O 的筆數 |

| 維修換貨＋換貨條碼 | 維修分類 = 維修換貨＋換貨條碼 的筆數 |
| 回廠QC | QC欄 = 回廠QC 的筆數 |
| 回廠報廢 | QC欄 = 回廠報廢 的筆數 |
| 回廠其他 | QC欄 = 其他 的筆數 |

## 樣式需求

| 項目 | 設定 |
|------|------|
| 字體 | 微軟正黑體 |
| 欄寬 | 自動調整至內容寬度 |

### 期間欄樣式規範（v4 新增）

「期間」欄的樣式必須與其他欄位完全一致，不可有特殊底色或字色：

| 位置 | 底色 | 字型 | 字色 | 對齊 |
|------|------|------|------|------|
| 標頭（第1列） | `D9E1F2`（淡藍）| 微軟正黑體、粗體 | 黑（預設） | 置中 |
| 資料列（第2列以下） | 無底色（`00000000`）| 微軟正黑體、一般 | 黑（預設） | 靠左 |

> ✅ 確認方式：選取 A欄任一資料列儲存格，確認「底色無填滿」，與 B 欄資料列相同。
