# 冊 03：分析總表 工作表規格

## 來源與輸出

| 項目 | 說明 |
|------|------|
| 來源檔案 | `設備品質分析_彙整總表.xlsx` |
| 輸出檔案 | `設備品質分析_分析總表_{YY}_{Qn}.xlsx`（例：`設備品質分析_分析總表_25_Q1.xlsx`） |

> **命名規則**：`{YY}` 為西元年後兩碼（25 = 2025），`{Qn}` 為季別（Q1、Q2…）。
>
> **v3 調整**：輸出檔案包含三個工作表（七、八、九），移除原有工作表一到六。
>
> **注意**：已使用年限欄位計算邏輯依 v3 規則（僅對回廠過保數明細計算平均值）。詳見冊 04 第三節。

## 工作表七：車機\_彙整總覽

**篩選條件：** 設備類型 = 車機 ／ 維護原因 = 訊號異常

**欄位（依序）與計算邏輯：**

| 欄位 | 來源／計算方式 |
|------|--------------|
| 期間 | 期間代碼，格式 `YYYY-Qn`，如 `2026-Q1`（**v4 新增，位於第一欄 A 欄**） |
| 類型 | 廠牌型號 |
| ERP品號 | ERP品號 |
| 品名 | 替換前品項 |
| 上線量 | 來自上線量欄位（同ERP品號對應值） |
| 失聯 | 維護類型 = 失聯 的筆數 |
| 定位不良 | 維護類型 = 定位不良 的筆數 |
| 訊號異常 | 維護類型 = 訊號異常 的筆數 |
| 其他 | 不屬於上列維護類型的筆數 |
| 回廠量 | AB點 + 失聯 + 定位不良 + 訊號異常 + 其他 |
| 回廠不良品數(全) | D + E + G + H + X + 維修換貨＋換貨條碼 + 回廠報廢 的筆數加總 |
| 回廠良品數 | O /測試正常 + 回廠QC + 其他(QC欄) 的筆數加總 |
| 回廠不良品數 | G + X + 維修換貨＋換貨條碼 的筆數加總 |
| 回廠過保數 | D + E + 回廠報廢 的筆數加總 |
| 回廠人為數 | H /人為報廢 的筆數 |
| D /停產報廢 | 維修分類 = D 的筆數 |
| E /過保報廢 | 維修分類 = E 的筆數 |
| G /評估後退修 | 維修分類 = G 的筆數 |
| H /人為報廢 | 維修分類 = H 的筆數 |
| O /測試正常 | 維修分類 = O 的筆數 |
| X /已完修 | 維修分類 = X 的筆數 |
| 維修換貨＋換貨條碼 | 維修分類 = 維修換貨＋換貨條碼 的筆數 |
| 回廠QC | QC欄 = 回廠QC 的筆數 |
| 回廠報廢 | QC欄 = 回廠報廢 的筆數 |
| 回廠其他 | QC欄 = 其他 的筆數 |
| 已使用年限 | 該分組回廠過保數明細的平均已使用年限（無過保記錄則空白）【v3】 |

## 工作表九：設備品質分析\_彙整總表

此工作表為彙整總表原始資料的完整備份，直接從 `設備品質分析_彙整總表.xlsx` 複製而來。

| 項目 | 說明 |
|------|------|
| 工作表名稱 | `設備品質分析_彙整總表` |
| 來源 | `設備品質分析_彙整總表.xlsx` → `彙整總表` 工作表（Step 1–8 產出，共 19 欄） |
| 欄位數 | 19 欄（完整欄位定義見冊 01 最終欄位表） |
| 用途 | 供冊 05 月趨勢計算使用；原始資料核查；跨期比較時的完整明細資料庫 |

### 嵌入步驟

1. 完成 Step 1–8 產出 `設備品質分析_彙整總表.xlsx`
2. 在分析總表 Excel 檔中新增工作表，命名為 `設備品質分析_彙整總表`
3. 將 `設備品質分析_彙整總表.xlsx` → `彙整總表` 工作表的全部資料（含標頭列）複製貼上
4. 確認欄位數為 19 欄、列數與中間產出一致

> **注意**：此工作表僅供資料備查與月趨勢計算，不用於 Streamlit 網站讀取。

## 樣式需求

| 項目 | 設定 |
|------|------|
| 字體 | 微軟正黑體 |
| 欄寬 | 自動調整至內容寬度 |

### 期間欄樣式規範（v4 新增）

「期間」欄的樣式必須與其他欄位完全一致，不可有特殊底色或字色：

| 位置 | 底色 | 字型 | 字色 | 對齊 |
|------|------|------|------|------|
| 標頭（第1列） | `D9E1F2`（淡藍）| 微軟正黑體、粗體 | 黑（預設） | 置中 |
| 資料列（第2列以下） | 無底色（`00000000`）| 微軟正黑體、一般 | 黑（預設） | 靠左 |

> ✅ 確認方式：選取 A欄任一資料列儲存格，確認「底色無填滿」，與 B 欄資料列相同。
