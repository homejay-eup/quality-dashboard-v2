## 工作表十：成本節省總覽

此工作表記錄各期間、各廠牌型號的「不送修」節省維運金額計算結果，供 quality-dashboard 成本節省分頁顯示。

| 項目 | 說明 |
|------|------|
| 工作表名稱 | `成本節省總覽` |
| 產出方式 | 冊 05 Step 5 Python 腳本自動計算寫入（不需手動操作） |
| 資料來源 | 各期 `設備品質分析_彙整總表`（工作表九）× `成本參數設定.xlsx` |
| 設備類型涵蓋 | 車機、鏡頭、配件、耗材（全四類，不限維護原因） |

### 欄位（依序）與定義

| 欄位名稱 | 格式 | 說明 |
|---------|------|------|
| 期間 | 文字 `YYYY-Qn` | 例 `2025-Q1`，與彙整總覽格式相同 |
| 設備類型 | 文字 | 車機 / 鏡頭 / 配件 / 耗材 |
| 廠牌型號 | 文字 | 同彙整總表廠牌型號欄位格式 |
| 廠商 | 文字 | 同彙整總表廠商欄位 |
| 不送修數量 | 整數 | 該分組中 `維修分類 = '不送修'` 的筆數 |
| 整新單價合計 | 整數（元）| 成本預估中同廠牌型號所有操作整新單價之加總（Option A） |
| 節省金額合計 | 整數（元）| `(整新單價合計 + 每件運費) × 不送修數量` |
| 耗費工時_分鐘 | 整數 | `每件工時(分鐘) × 不送修數量` |
| 工時成本_元 | 整數（元）| `耗費工時_分鐘 × 時薪 ÷ 60`，四捨五入至整數 |

**欄位總數：9 欄**

### 計算公式說明

```
整新單價合計（Option A）：
  同一廠牌型號若在成本預估中有多列（如整新 + 整線），
  加總所有操作的整新單價。
  例：鏡頭 HS = 1050（整新）+ 500（整線）= 1550

節省金額合計：
  (整新單價合計 + 130) × 不送修數量
  例：HS 10 台 = (1550 + 130) × 10 = 16,800 元

耗費工時_分鐘：
  3 × 不送修數量（每件固定 3 分鐘）

工時成本_元：
  耗費工時_分鐘 × 196 ÷ 60，四捨五入
  例：30 分鐘 = 30 × 196 ÷ 60 = 98 元

（時薪 196、每件運費 130、每件工時 3 均來自成本參數設定.xlsx，可調整）
```

> **整新單價合計 = 0 的列**：表示該廠牌型號尚未在成本預估中設定，節省金額合計僅計運費部分（= 130 × 不送修數量）。需補充 `成本參數設定.xlsx` → `成本預估` 後重跑腳本。

### 排序規則

期間降冪（最新在前）→ 設備類型升冪 → 廠牌型號升冪
