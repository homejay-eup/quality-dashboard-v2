# 共用雲端快照接收端 — 部署說明

> 一次性設定。做完後，工具的「匯出本期快照」與「生成落地頁報告」會自動把檔案存進你指定的共用 Drive 資料夾，任何人執行都一樣。

## 為什麼需要這個

工具是純前端網頁，瀏覽器基於安全限制**不能**自動寫入你的網路磁碟或 Google Drive，只能觸發「下載」。這支 Apps Script 是一個很輕的中介：工具把檔案內容 POST 給它，它用你的 Google 身分把檔案寫進共用 Drive 資料夾；也提供清單/讀取，讓工具能列出歷史快照供跨期比較。

資料只在「你的瀏覽器 → 這支 Apps Script → 你的 Google Drive」之間流動，不經過任何第三方伺服器。

## 部署步驟

1. **建立共用資料夾**：在 Google Drive 建一個資料夾（例如「設備品質分析\_快照」），設定給需要的同事共用檢視/編輯權限。打開資料夾，網址列會是：
   `https://drive.google.com/drive/folders/1AbCdEfGhIjKlmNo...`
   複製最後那一段（`1AbCdEfGhIjKlmNo...`）——這是資料夾 ID。

2. **建立 Apps Script 專案**：前往 [script.google.com](https://script.google.com) → 新專案。把本資料夾的 `Code.gs` 內容整個貼進去（取代預設的 `myFunction`）。

3. **填入資料夾 ID**：把檔案最上面 `const FOLDER_ID = '請填入共用資料夾ID';` 改成步驟 1 複製的 ID。

4. **部署為 Web App**：右上角「部署」→「新增部署作業」→ 類型選「網頁應用程式」：
   - 執行身分：**我**（你的帳號，這樣它才有權限寫入你的 Drive）
   - 具有存取權的使用者：**任何人**（或「貴機構內的任何人」，若想限制只有公司內部能用；純前端頁面對外公開時建議選「貴機構內的任何人」比較安全）
   - 部署後會拿到一組網址，形如：
     `https://script.google.com/macros/s/AKfycb.../exec`

5. **把網址貼進工具設定**：打開 `js/config.js`，把 `CLOUD_ENDPOINT` 改成上面那組網址（詳見檔案內註解）。

6. **測試**：重新整理工具頁面，按「匯出本期快照」，確認共用資料夾裡出現一個 `.json` 檔；「對比期間」下拉選「☁️ 從共用雲端選取快照…」應該能看到清單。

## 之後要換資料夾／重新部署

- 換資料夾：改 `FOLDER_ID` 後不需重新部署，Apps Script 會即時生效。
- 改程式碼（例如以後我再調整 `Code.gs`）：貼上新版 → 「部署」→「管理部署作業」→ 選現有部署 → 編輯 → 版本選「新版本」→ 部署（**網址不會變**，工具端 `CLOUD_ENDPOINT` 不用改）。

## 已知限制

- 單次上傳檔案大小建議在 Apps Script 配額內（目前快照約 30–40MB，隨資料成長會再變大）。若之後上傳開始失敗，回報給我評估壓縮或改用 Google Drive API 的分段上傳。
- 未部署／`FOLDER_ID` 未填之前，工具的雲端功能會自動隱藏或提示，本機下載/載入快照檔仍照常可用，不受影響。
